# Contributor and agent guidance

This repository is the public GitHub profile README. It summarizes selected
work; it is not a second project-status database or a place for private planning.

Before editing, read `README.md` and verify every lifecycle, capability, release,
and current-work statement against the linked public repository.

## Validation and publication

The repository is documentation-only. Run:

```bash
git diff --check
```

Also inspect Markdown rendering and every changed link. Do not add activity
claims, support promises, benchmark results, adoption metrics, badges, or
production-readiness language without durable public evidence.

Never include private repository names, local paths, host or network details,
personal records, credentials, unpublished plans, or volatile internal status.
Respect the license and attribution of any copied text or media; do not add a
software license mechanically to profile prose.

Use a focused feature branch. Commit and push the validated change and open a
pull request; incomplete or uncertain claims stay draft. After publication,
send the exact commit, PR, validation, outcome, risks, and next action to the
repository's external coordination record. Do not claim completion until that
remote handoff is verified.
